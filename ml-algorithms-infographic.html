Linear Regression Supervised

Tabular Data

Use case: Predict house prices from size, location and number of rooms.

How it works: Fits a straight line through the data to describe the relationship between input features and a continuous numeric target.

Naive Bayes Supervised

NLPTabular Data

Use case: Spam filtering, sentiment analysis and news-topic classification.

How it works: Applies Bayes' theorem with a simplifying assumption that features are independent, to estimate the probability of each class.

Logistic Regression Supervised

Tabular DataNLP

Use case: Classify an email as spam or not; estimate customer churn or credit default.

How it works: Combines features into a weighted sum, then passes it through an S-shaped curve to output a probability between 0 and 1.

Convolutional Neural Network (CNN) Supervised

Computer Vision

Use case: Detect tumours in medical scans; recognise objects in photos.

How it works: Learns visual features with stacked filters and pooling layers, building from edges to shapes to whole objects.

Decision Tree Supervised

Tabular Data

Use case: Approve or decline a bank loan using income, credit history and debt.

How it works: Splits data with a series of yes/no questions on features until each branch ends in a prediction.

k-Means Clustering Unsupervised

Tabular DataComputer Vision

Use case: Segment customers by behaviour; compress image colours.

How it works: Picks k centres, assigns each point to the nearest one, moves each centre to its group's average, and repeats until stable.

Random Forest Supervised

Tabular Data

Use case: Detect fraudulent transactions in a bank.

How it works: Combines predictions from many decision trees, each trained on a random sample, to improve accuracy and robustness.

Principal Component Analysis (PCA) Unsupervised

Tabular DataComputer Vision

Use case: Compress high-dimensional data into a few factors for visualisation or faster models.

How it works: Rotates the data onto new axes that capture the most variance, then keeps only the strongest ones.

Support Vector Machine (SVM) Supervised

Computer VisionNLPTabular Data

Use case: Recognise handwritten digits; classify documents by topic.

How it works: Finds the boundary with the widest margin between classes; kernels let it model non-linear patterns.

Generative Adversarial Network (GAN) Unsupervised

Generative AIComputer Vision

Use case: Generate synthetic faces, product concepts or training images.

How it works: A generator creates samples while a discriminator critiques them; the two networks improve through competition.

How they differ

  • Predict a numberLinear Regression
  • Predict a categoryLogistic Regression, Decision Tree, SVM
  • Discover groupsk-Means
  • Simplify featuresPCA
  • Create new contentGAN

Algorithm choice depends on the data, the target, interpretability needs and available labels.
